# Бумажки

Мобильная игра-кликер на React Native, Expo и TypeScript, разрабатываемая в рамках курсового проекта.

Игрок нажимает на стопку бумаги, зарабатывает бумажки и покупает улучшения. Визуальный стиль — бумажная аппликация, а игровые предметы содержат отсылки к Deadlock, стримингу и программированию.

## Планируемые возможности

- Регистрация и вход.
- Улучшения клика и источники пассивного дохода.
- Заработок во время отсутствия.
- Перерождение с постоянными бонусами.
- Сохранение прогресса и настройки игры.

## Запуск

Установить зависимости:
`npm install`

Запустить проект:
`npx expo start`

Открыть приложение на телефоне через Expo Go.
